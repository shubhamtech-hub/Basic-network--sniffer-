# Basic Network Sniffer

This is a simple network sniffer project made using Python and Scapy. 
It helps us see basic information about the network packets passing through the computer.

## Features

- Captures IP packets from the network
- Shows the source IP address
- Shows the destination IP address
- Displays the protocol used
- Shows the size of each packet
- Captures a limited number of packets

## Technologies Used

- Python
- Scapy
